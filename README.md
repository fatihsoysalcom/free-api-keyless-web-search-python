# Free API Keyless Web Search Python

This example demonstrates how to perform a basic web search without requiring an API key, using only Python's standard library. It leverages the DuckDuckGo Instant Answer API to fetch a summary for a given query, illustrating a cost-effective way to integrate web information into applications like OpenClaw.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal:
`python main.py` and follow the prompt, or
`python main.py <your query here>`
